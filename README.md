de Machine Learning caixa-preta interpretáveis usando XAI e LIME, 
com base nos princípios do Privacy by Design.

### 📁 Beaba — Sistema de Gerenciamento de Templates
Sistema desenvolvido sozinha em Python para automatizar a criação,
